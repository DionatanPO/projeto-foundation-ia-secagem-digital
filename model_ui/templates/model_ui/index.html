Bem-vindo ao SolumAI

Olá! Que bom te ver por aqui 👋

Este é seu assistente inteligente da fazenda. Ele ajuda você a cuidar da secagem e armazenagem de grãos de um jeito simples: é só conversar, como no WhatsApp. Sem complicação.

💬Pergunte com palavras simples.
Ex: “Qual a umidade ideal da soja?” ou “Meu milho está demorando a secar, o que faço?”
📸Mande foto ou fale por voz.
Envie foto do painel, do silo ou do grão, ou clique no microfone para ditar.
📚Resposta com base técnica.
Ele consulta manuais e documentos da fazenda antes de responder.
🔄Funciona com IA Local e Remota.
🏠 Local: roda aqui na sua máquina, privada e funciona até sem internet.
☁️ Remota: conecta em modelos potentes como Claude e GPT. Você troca quando quiser nas Configurações.
🔒 No modo Local, seus dados ficam 100% nesta máquina. Nada vai para a internet.

Configurações

Processamento
💡 GPU e VRAM: o modelo precisa caber inteiro na VRAM da placa (ex.: um 8B quantizado pede em torno de 5–6 GB livres). Se não couber, o carregamento falha ou fica muito lento — nesse caso use CPU ou um modelo menor/mais quantizado.
■ NVIDIA: aceleração plena via CUDA, com o melhor desempenho.
■ AMD: no Windows o suporte é via Vulkan, com desempenho e compatibilidade mais limitados; se der erro, volte para CPU.

Documentos da base (RAG)

Criatividade 0.1
Diretriz do Sistema
Privacidade: Ao utilizar o modelo local, todos os dados permanecem na sua máquina. Nenhuma informação é enviada para servidores externos. Seus dados estão 100% protegidos.
Ativar Modelo Remoto
Quando ativo, as mensagens serão enviadas para a API remota em vez do modelo local.
Atenção: Ao utilizar um modelo remoto, seus dados serão enviados para servidores externos e não estão protegidos. Podem ser usados para treinamento de modelos de IA. Certifique-se de não enviar informações sensíveis ou confidenciais.
URL do OpenCode Server
URL do servidor OpenCode (ex: http://127.0.0.1:4096). Execute opencode serve no terminal.
Modelo (opcional)
Ex: anthropic/claude-sonnet-4-5 ou openai/gpt-4o
Como manter o servidor rodando

Execute o comando abaixo no terminal para iniciar o servidor OpenCode. O servidor deve permanecer aberto enquanto usar o modelo remoto.

opencode serve --port 4096
Dica: Use --hostname 0.0.0.0 para acessar de outros dispositivos na rede.
